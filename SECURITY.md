# Security Policy

## Reporting a Security Issue

If you find a security issue in this portfolio repository, please do not create a public issue.

Please contact the repository owner privately so the issue can be reviewed before any public disclosure.

## Scope

This repository contains portfolio evidence, scripts and write-ups for defensive cybersecurity activities. The main risks are accidental exposure of personal information, credentials, tokens or unsafe example code.

## Security Practices Used

- No real passwords, API keys or private tokens should be committed.
- Example credentials must be clearly marked as fake.
- Screenshots should be checked for personal information before being included.
- Dependencies should be reviewed before use.
