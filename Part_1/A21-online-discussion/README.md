# A21. Participate in an online cybersecurity discussion.

**Overview:** I participated in two separate discussions on Reddit (as removal85_snuggle) related to malicious extensions and prompt poaching.

- I created a post on `r/Cybersecurity101` titled “Are extensions a security risk (Firefox)”, where I asked whether extensions with tab access a security risk are, and whether it is safe to enable them in private browsing. The post received several replies. One of them pointed out that while security checks exist, there are insufficient, and that extensions can be pushed malicious updates even after installation. This is since permissions are granted and remain granted regardless of whether they are actively being used (and for what purpose). I replied that a good mitigation for that would be to disable automatic updates and to wait for the extension to be out a while before installing. Another user also explained that extension developers are actively being offered money to insert malicious code and recommended some security tools to verify extensions.
- The other discussion was a comment of `r/cybersecurity` in response to a post titles “Prompt Poaching is the best argument for Zero Trust Browsing in 2026”, which discussed malicious browser extensions silently scraping AI chat tabs to exfiltrate data. I commented that if people push back on stricter browser policies, they probably do not realise how much sensitive data ends up in these AI chat sessions, and that awareness of scraping behaviour would likely shift their perspective.
