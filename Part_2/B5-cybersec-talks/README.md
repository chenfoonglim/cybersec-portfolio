B5. Attend 2 cybersecurity related talks/seminars.
Overview: I attended two cybersecurity related CITS2006 sessions (week 11 and week 12). The first was about Cyber Threat Intelligence, and the second was about AI and Security. Both sessions were presented by guest speakers and was extremely relevant to defensive cybersecurity as they focused on how organisations understand threats, and how AI can be used or misused in a security context. 
1.	Cyber Threat Intelligence: This session was about CTI, which is the process of turning raw security data into useful information that can be used to support security decisions. One important point from the session was that raw data is not the same as intelligence. For example, an IP address attempting many logins is only raw data or information, but once we analyse it in context, it may become intelligence that indicates a brute force attack.
The session also covered different CTI sources, such as internal logs, EDR data, OSINT, government agencies, threat feeds and dark web monitoring. 
 
2.	AI and Security: This session was about the relationship between AI and cybersecurity, especially how machine learning and large language models can be used in different security tasks. The speaker explained the machine learning pipeline, including data collection, training, evaluation and also inference. This shows how AI can directly connect to security tasks such as spam detection, malware detection and vulnerability detection. One part that stood out to me was the discussion about using LLMs for code vulnerability detection. The session showed that LLMs can flag vulnerable code, but they can also miss vulnerabilities, misclassify CWE categories, or just straight invent issues that do not exist. This means that AI can be useful for security, but it should not blindly be treated as factual. A human would still need to review the output, especially as in cybersecurity, false positive and false negatives can have serious consequences.
