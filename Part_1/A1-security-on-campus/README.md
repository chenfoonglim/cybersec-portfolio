# A1. Discover security concepts used on campus.

**Overview:** For this task I have researched, identified and analysed security concepts implemented at the University of Western Australia (Crawley Campus), covering both physical and digital security. Images are gathered through on campus observation and have been attached as evidence.

**Security Concepts Found**

1. **CCTV Surveillance**
    - Type: Physical (Detective)
    - Found around building entrances, pathways, and within campus buildings. CCTV cameras can record activity across the campus and be sent to the Security Operations Centre, which operates 24/7 as mentioned in UWA’s website under “UWA Security services”. This can be used for incident investigation and acts as a deterrent.
2. **Gallagher Access Control Systems for Buildings and Rooms**
    - Type: Physical (Preventive)
    - Found around building entrances like Reid library, lecture theatres, toilets, computer rooms and library study zones. They use RFID technology with MIFARE standards (according to Gallagher). The card reader restricts access to spaces and requires a student or staff card to access. As an example, Reid library requires student cards to access after-hours, and Level 4 of Reid library specifically uses this card reader to restrict the floor to post graduate students.
3. **24/7 Security Officers Patrol**
    - Type: Physical (Deterrent and Responsive Control)
    - UWA has Security Officers conducting regular patrols across campus grounds and buildings. According to UWA, they can “answer security questions, check building parameters, patrol parking areas and pathways, and perform identification when necessary”. This can be seen at night at Reid library, as security officers perform identification checks to everyone at Reid after hours to ensure they are all UWA students, and asking those who are not to leave.
    - According to their UWA’s website, Security Operation Officers have also received certificate 2 in security operations, and some certificate 3, with first aid and mental health first aid, and experience in security industries.
4. **Emergency Help Points**
    - Type: Physical (Responsive)
    - Help point stands coloured blue and white are located through the campus. Each stand has a red button that when pressed, gives a direct connection to security without the need to dial.
5. **SafeZone App**
    - Type: Digital (Responsive control)
    - This application connects UWA student and staff to UWA’s security team. It provides features such as Emergency assistance, first aid assistance, non-urgent help, wellbeing support, check in timer, safety updates and also campus navigation
6. **1X Network Authentication (Eduroam)**
    - UWA’s Unifi network uses IEEE 802.1X for network authentication, verified through my laptop’s network settings which show authentication vis EAP-PEAP (MSCHAPv2). When a device connects, it must authenticate before being granted network access.
7. **Multi-Factor Authentication**
    - Type: Digital (Preventive)
    - All UWA systems (LMS, email, student connect) has an additional layer of authentication after entering the user email and password, where users must also verify via an authenticator (Microsoft Authenticator) code. This means that stolen passwords alone will not be sufficient to access accounts
8. **After-Hours Escort Service**
    - Physical (Responsive and preventive)
    - Campus wide service allowing any student or staff member to call UWA security after hours for an officer to escort them to their destination. This is a human-layer control for protecting students or staff during higher risk periods.
