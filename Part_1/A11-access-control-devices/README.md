# A11. Discover 5 unique access control devices.

**Overview:** An access control device is any physical or digital mechanism that verifies the identity of an individual before granting or denying access. Access controls rely on one or more of three factors: Something you have, something you know, or something you are. I identified five distinct access control devices around me.

1. **RFID Student Card**
    - My UWA Student card uses the Gallagher access control system, which uses encrypted RFID cards operating over NFC. These cards most likely use `AES-128` hardware encryption. Making the chip virtually impossible to clone. When tapped, the card and reader perform a mutual authentication challenge before granting access. This is considered a “something you have” device, meaning access is granted based on you having the card.
2. **iPhone PIN Pad**
    - The iPhone passcode keypad is a “something you know” access control device that controls access to the contents of the phone using a secret numerical code. The PIN is never stored as plaintext, rather it is processed through the Secure Enclave which combines it with the device’s hardware UID to derive the encryption key that unlocks the device. The phone also enforces attempt limiting, and after 10 failed attempts, the device can be configured to erase all data. This is implemented to prevent brute force attacks.
3. **MacBook Touch ID (Fingerprint)**
    - The Touch ID sensor on my laptop is a biometric access control device that verifies my identity before allowing access to the data stored. It controls access using fingerprint recognition. When a finger is placed on the sensor, the fingerprint would be captured and turned into a mathematical representation which will be used to compare against the stored template inside the Secure Enclave. Touch ID is therefore a “something you are” access control device.
4. **Google Authenticator (TOTP)**
    - Google Authenticator is a software-based access control device that generates a Time-based One-Time Password (TOTP) used for two factor authentications (2FA). Every 30 seconds, both the app and server independently compute an `HMAC-SHA1` hash (standard specified in `IETF RFC 6238`) of the shared secret that is exchanged on setup, combined with the current timestamp, producing the same 6-digit code without any network communication. This is a “something you have” device, and access requires both the account password and the current TOTP code. The code changes every 30 seconds and is mathematically derived from both ends so it cannot be intercepted.
5. **Car Key Fob (Rolling Code)**
    - A car key fob is a wireless access control device that uses rolling code cryptography to authenticate to the vehicle. Rolling codes are used in keyless entry systems to prevent replay attacks. This is when an eavesdropper records the transmission and replays it later to cause the receiver to unlock. A rolling code system ensures that the fob never sends the same code twice. Both the car and fob share a synchronised pseudorandom number generator, so the car only accepts codes within the next expected window of values (a window is necessary to prevent the key and car values to go out of sync after a few presses). If the number matches, then authentication is successful and the individual with the key is allowed access to the car.
