# A19. Join a CS/DS/cybersecurity club.

**Overview:** I joined Coders for Causes (CFC), a UWA student club that has workshops that build software projects for non-profit community organisations. Members who join workshops on the advanced level can collaborate real-world development projects, while beginners can learn web development from scratch.

I registered as a member on the CFC website, with the membership valid until March 2027, and joined their official discord server, which is their main communication platform. The server includes channels for coding help, resources, career advice, workshops, and cloud announcements.
