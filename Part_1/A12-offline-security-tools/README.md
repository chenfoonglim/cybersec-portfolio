# A12. Discover 5 unique offline security tools.

**Overview:** An offline security tool is any physical mechanism used to protect assets, detect unauthorised access, or to deter threats without requiring an internet connection. I identified 5 distinct offline security tools from my daily life.

1. **Physical Key and Locks**
    - **A physical key and lock** is one of the oldest and broadly used security tool. The lock mechanism contains a series of pins or tumblers of specific heights, which the correct key matches by raising each pin to the exact height needed to allow for the cylinder to rotate and unlock. Without the right key, the pins are misaligned and the lock will not be able to be opened. These do not require power, network nor software, making it immune to cyber-attacks, but rather physical attacks. The security of the lock and keys depend on the physical complexity of the key cut pattern, and the quality of the lock mechanism.
2. **RFID Blocking Wallet**
    - An RFID blocking wallet contains a layer of metallic material, typically a copper or aluminium mesh that blocks radio frequency signals from penetrating the wallet, which prevents contactless card readers from communicating with RFID or NFC cards without the owner’s knowledge. This prevents card skimming, which is where an attacker uses a concealed reader to silently read card details from a distance. Without this RFID blocking wallet, a reader held within a few centimetres could potentially extract card information in a public space.
3. **Apple Passwords App**
    - The Apple Passwords app is a built-in offline security tool that securely stores passwords, passkeys and credentials on device. All stored passwords are encrypted using AES with keys that are managed by the Secure Enclave. To access the app, the device passcode or biometrics (face ID or Touch ID) is required. When synced via iCloud, passwords are end to end encrypted.
4. **Safe (Key and Combination)**
    - A safe is a hardened physical security container used to store valuables, documents or sensitive items. They often use two types of locking mechanisms, a physical key or a combination dial (or both). The combination dial works by aligning a series of internal disks at a specific rotational position. The bolt retracts only when all the discs align correctly allowing the safe to open. The safe is also made from reinforced steel to resist any form of physical attacks. This makes them suitable for storing items that require both access control and physical protection. This specific model is also fire resistant.
5. **Electronic Article Surveillance (EAS) Security Tag**
    - EAS security tags are security devices to retail merchandise to prevent theft. They contain a circuit that triggers an alarm at the store exit gates if not properly deactivated at the point of sale. These are considered detection-based security tool, alerting when theft occurs, and deterring potential shop lifters through the threat of detection.
